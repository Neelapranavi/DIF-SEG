# Dataset

Place paired segmentation data here:

```text
dataset/
├── images/
│   ├── image_001.png
│   └── image_002.png
└── masks/
    ├── image_001.png
    └── image_002.png
```

Image and mask filenames must match. Masks should contain background and foreground regions.

Do not commit private, identifiable, or restricted medical data to a public repository.
